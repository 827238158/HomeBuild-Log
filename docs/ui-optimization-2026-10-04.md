# 全页面 UI 优化 · 2026-10-04

根据本日 Impeccable 审查的 17 项问题，修复所有主页面及相关抽屉、编辑与二级入口。保留中文系统字体、已确认视觉、来源确认流程、API 原有业务语义和账本统计口径。新增附件内容读取接口，不迁移数据库。

## 修复对应表

| 审查项 | 本次处理 |
|---|---|
| 1 核心事实 | 六类记录增加只读字段，独立显示金额、交易对象、原始尺寸与单位、决策选项和选择等。 |
| 2 草稿丢失 | 主导航、详情关闭、退出和浏览器离开增加未保存保护；踩坑草稿按表单/记录保留在浏览器会话，保存或明确放弃后清理。 |
| 3 请求竞态 | 记录分析及 AI 运行范围只接受当前请求结果，更新中隐藏旧数据，迟到响应不覆盖新条件。 |
| 4 下拉键盘 | 共享 Select 采用完整 combobox 入口，支持 Enter、Space、方向键、Esc、字段名称与错误提示；多选 portal 进入浮层 Tab 顺序。 |
| 5 隐藏导航 | 手机导航关闭时 inert 并退出可访问树；打开后隔离背景，选择/关闭后焦点回到导航入口。 |
| 6 抽屉键盘 | 通用详情、账本明细及导航使用统一浮层栈，管理 Tab、顶层 Esc、背景隔离、滚动锁定和焦点归还；编辑切换明确转移焦点。 |
| 7 图表操作 | 可点击分类图表增加“按分类操作”按钮列表；问题严重程度与分析状态增加等价筛选。 |
| 8 文字对比 | 加深说明文字令牌，保留字体和既有语义色。 |
| 9 证据直达 | 来源、关联记录和调研主题增加直达；附件经请求头鉴权读取 blob，可查看或下载，收起/卸载释放 URL。 |
| 10 静态健康文案 | 改为“本地装修工作台”和“已登录”，避免把登录态当作实时服务健康。 |
| 11 查询恢复 | 概览、时间线、账本、问题、空间、分析与搜索提供就近重试。 |
| 12 详情依赖 | 主体独立读取；来源、关联和审计单独失败与重试，编辑参考资源仅进入编辑时加载。 |
| 13 筛选语义 | 清除恢复所有对应筛选；搜索状态使用类型限定和业务标签。 |
| 14 空间入口 | 空间页与空态直达录入页的空间管理区域并聚焦名称。 |
| 15 完成结果 | 用内联多行表单替换 prompt；空值就近校验、失败保留输入，保存过程中阻止重复提交。 |
| 16 字段命名 | 快速记录、日期、候选及登录字段补齐名称，登录错误可播报并阻止重复请求。 |
| 17 触屏目标 | 窄屏或粗指针下主要按钮、来源操作、下拉和录入标签至少 44px；桌面保持紧凑。 |

## 验证边界

- 自动化回归覆盖迟到请求、草稿保护、来源独立重试、核心字段、附件鉴权与释放、菜单键盘、浮层隔离及问题完成失败恢复。
- 后端附件内容接口检查登录、允许的 MIME、文件存在及路径必须位于附件原件目录；缺失和越界返回 404，响应禁止缓存并启用 nosniff。
- 浏览器只查看真实数据、打开与取消编辑，没有保存、删除、确认或分析真实记录。桌面 1440×900 和窄屏 390×844 主页面无整页横向溢出，1280×720 核对账本嵌套详情与编辑。
- Impeccable 原始检测有既有 11 条样式线索：侧边/顶部语义边框及局部标签/录音柱动画；没有新命中，不据此删除已确认视觉。styles.css 的 7 条语义边框提示已登记两条仅限该文件的忽略规则，保留其他文件检测；目标文件复扫无命中。既有 ECharts 大包构建提示与 SQLite datetime adapter 弃用提示保留。
- 实际手机/平板、WebKit、触摸手势、200% 放大和长时间性能仍待验收。附件真实 HEIC/PDF 显示取决于设备浏览器，提供原件下载；本轮使用隔离测试数据核对附件接口。

代码尚未提交、推送或部署。最终测试计数和预览运行状态以 memory/CURRENT.md 的本日快照为准。
