# 任务总览

## 使用方式
- 新任务从 `TASK-TEMPLATE.md` 复制，文件名建议使用 `YYYYMMDD-简短主题.md`。
- 创建任务时先确定单一目标、范围、非目标、依赖、风险和验收标准。
- 开始工作前按根目录 `AGENTS.md` 输出 `Need:`，只读取当前步骤需要的资料。
- 任何写入前必须检查并认领`ACTIVE.md`；同一时刻仅允许一个执行Agent修改项目。
- 状态变化时同步更新本页；任务完成后保留任务文件作为实施与验收记录。

## 状态定义
- `待梳理`：目标或边界尚不完整。
- `可开始`：依赖与验收标准已明确。
- `进行中`：正在执行，原则上应有明确负责人。
- `受阻`：存在无法在当前授权或条件下解决的阻碍。
- `待验收`：实现与自检已完成，等待验收。
- `已完成`：验收通过且审查、文档更新判断均已完成。
- `已取消`：明确不再继续，并记录原因。
