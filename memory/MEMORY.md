# HomeBuild Log Memory

## 一句话

HomeBuild Log 是本地优先的装修事实工作台：保存原始来源，生成候选记录，由用户确认后进入时间线、账本、问题、空间、记录分析、智能分析和搜索。

## 稳定事实

- 产品用户：单一业主本人，个人私用。
- 技术基线：React、TypeScript、Vite、FastAPI、SQLite、本地附件目录。
- 部署入口：`ubuntu26` 的 Docker 服务使用家庭有线局域网；最近确认的地址、镜像、数据库版本和验收状态统一见 `memory/CURRENT.md`。
- 数据目录：项目根目录 `.local-data/`，不得进入 Git。
- 来源录入：文字必填，可附加单个图片或 PDF 作为证据；当前不对附件做 OCR 或视觉理解。
- 附件查看：记录详情通过登录鉴权读取原件，可查看或下载；令牌只放请求头，前端临时 blob URL 在收起/卸载时释放。
- AI：只分析来源文字，默认关闭；MiMo 和 DeepSeek 可作为 OpenAI 兼容供应商，本地规则兜底。
- 正式记录：事件、账目、问题、尺寸、决策、调研。
- 尺寸：使用可增减的命名尺寸项，保留原顺序、重复测点及未知方向；输入支持毫米、厘米、米，保存统一毫米，切换单位保持实际尺寸。近似值、误差口径、方法及测量时间单独保存。“再次测量”创建关联的新记录，清空旧数值与来源，不覆盖旧事实、不自动采用最新值；复测历史通过相关记录查看。
- 账目：只记录付款、退款、收入；金额统一人民币，净支出为付款减退款再减收入。
- 待办与问题：待办、普通问题和施工问题仍复用 `issue` 类型，显示名称为“待办与问题”，状态为待处理、处理中、已完成。
- 调研笔记：独立入口复用 `research` 正式记录，快速创建保留原始来源；只保留主题与追加式调研过程、来源和待确认事项。状态为待调研、调研中、已归档，可恢复继续研究。结论功能停用，旧字段及历史表保留读取兼容，写入接口禁止结论更新；旧 `concluded` 在读取、筛选及统计中按 `comparing`（调研中）处理，不批量改写真实数据。
- 公共下拉：单选、多选、来源选择与来源操作共用 `useDropdown` 的互斥、外部关闭、Escape及无滚动焦点恢复，使用 `DropdownChevron` 表达展开状态；定位复用 `useDropdownPosition`，Portal菜单只滚动自身，不使用活动选项的祖先 `scrollIntoView`。
- 核心原则：原始事实优先、人在回路、一事多记录、视图不是副本、不确定性显式化、本地与隐私优先。

## 默认读取

新任务默认只读取：

```text
AGENTS.md
memory/MEMORY.md
memory/CURRENT.md
```

然后根据任务类型按需读取：

- UI、页面、组件、视觉：`PRODUCT.md`、`DESIGN.md`；按需使用 `.agents/skills/impeccable/SKILL.md`，接入与更新见 `docs/impeccable.md`。Windows 命令统一走 `scripts/impeccable.cmd`。
- 启动、测试、构建、部署、迁移：`memory/RUNBOOK.md`。
- 已知异常、环境坑、恢复方式：`memory/PITFALLS.md`。
- 重要操作、部署、迁移或长期决策的历史事实：`memory/LOG.md`。
- 数据库迁移：`backend/migrations/README.md`，再读当前 head 或目标迁移。
- 具体实现：优先用 `rg` 搜索代码入口、类型、接口、测试和样式。

## 检索规则

- 项目级 Hook 会定向注入命中的 PITFALLS/LOG 片段，并在每轮结束前触发一次记忆审计续行；它不自动写记忆，也不保存完整工具日志。
- 文档负责记方向、边界和长期事实；代码搜索负责确认实际影响范围。
- 任务涉及多个代码入口时，必须搜索调用方、类型定义、测试和样式，不能只靠文档判断。
- 不要默认读取历史任务、旧路线图、旧检查清单或全量迁移。
- 信息不足时追加新的 `Need:`，说明下一步需要读取什么。

## 记忆职责

- `MEMORY.md`：稳定事实与检索路由，不记录动态部署版本和测试计数。
- `CURRENT.md`：带确认日期的最近运行状态、当前未完成的工作及待验收事项；不把历史状态写成当前事实。
- `LOG.md`：重要操作与长期决策的当次事实；已完成事项不在 CURRENT 重复展开。
- `PITFALLS.md`：可复用的触发条件、原因和处理；尚未重新验证的问题明确标记为历史观察。
- `RUNBOOK.md`：可复用的操作命令和步骤；`DESIGN.md`：UI 设计经验与体验底线。
- 普通进度、工具日志、模拟失败和已核对的误报不归档；不能为了通过 Hook 而写记忆。
