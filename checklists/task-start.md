# 任务开始检查

- [ ] 已用一句话写清任务目标，并确认交付物和验收标准。
- [ ] 已确认范围、非目标、依赖、权限边界和风险操作。
- [ ] 已在 `tasks/` 创建或更新任务文件，并在 `tasks/README.md` 同步状态。
- [ ] 涉及写入时已检查`tasks/ACTIVE.md`，确认没有其他Agent占用，并认领唯一写入权。
- [ ] 已在任务中记录当前执行Agent和允许修改的文件；其他Agent保持只读。
- [ ] 已判断是否需要项目规格、架构、风格、契约、流程或决策记录。
- [ ] 已输出 `Need:` 列表，且只读取当前步骤真正需要的文件。
- [ ] 已把不确定内容标为「不确定」或「需要验证」，未猜测 API、命令、版本或项目结构。
- [ ] 涉及 Python 时已确认解释器和环境；涉及依赖安装时已确认 pip 与解释器一致。
- [ ] 涉及数据、附件、金额或自动识别时，已考虑隐私、原始证据、置信度与人工确认边界。
